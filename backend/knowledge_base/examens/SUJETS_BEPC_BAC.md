## BEPC — Brevet d'Études du Premier Cycle

### BEPC Mathématiques — Sujet Type A

**EXERCICE 1 (5 points) — Algèbre**
1. Résoudre dans ℝ l'équation : 3x² - 12 = 0
2. Résoudre le système : { 2x + y = 7 ; x - y = 2 }
3. Factoriser : A = x² - 6x + 9

*Corrigé :*
1. 3x² = 12 → x² = 4 → x = 2 ou x = -2
2. Addition des deux équations : 3x = 9 → x = 3 ; puis y = 7-6 = 1. Solution : (3 ; 1)
3. A = (x-3)² (identité remarquable a²-2ab+b²)

**EXERCICE 2 (5 points) — Géométrie**
Dans un triangle ABC rectangle en A, on a : AB = 5 cm et BC = 13 cm.
1. Calculer AC.
2. Calculer sin(B), cos(B) et tan(B).
3. En déduire la valeur de l'angle B (utiliser la calculatrice).

*Corrigé :*
1. AC² = BC² - AB² = 169 - 25 = 144 → AC = 12 cm
2. sin(B) = AC/BC = 12/13 ≈ 0,923 ; cos(B) = AB/BC = 5/13 ≈ 0,385 ; tan(B) = AC/AB = 12/5 = 2,4
3. B = arcsin(12/13) ≈ 67,38°

**EXERCICE 3 (5 points) — Statistiques**
Les notes de 10 élèves de 3ème à l'épreuve de maths sont :
8 ; 12 ; 15 ; 10 ; 14 ; 9 ; 12 ; 16 ; 11 ; 13
1. Calculer la moyenne.
2. Trouver la médiane.
3. Quelle est la note la plus fréquente (mode) ?

*Corrigé :*
1. Somme = 120 → Moyenne = 120/10 = **12**
2. Notes triées : 8,9,10,11,**12,12**,13,14,15,16 → Médiane = (12+12)/2 = **12**
3. Mode = **12** (apparaît 2 fois)

## BAC — Baccalauréat Cameroun

### BAC Série C — Mathématiques — Sujet Type

**PROBLÈME I (8 points) — Analyse**

Soit f la fonction définie sur ℝ par : f(x) = x³ - 3x + 2

1. Calculer f'(x) et déterminer le signe de f'(x).
2. Dresser le tableau de variations de f.
3. Calculer les coordonnées des extrema locaux.
4. Calculer ∫₀² f(x)dx.
5. Tracer la courbe dans un repère orthonormé.

*Corrigé :*
1. f'(x) = 3x² - 3 = 3(x²-1) = 3(x-1)(x+1) ; f'(x) > 0 si x < -1 ou x > 1 ; f'(x) < 0 si -1 < x < 1
2. Tableau : croissant sur ]-∞;-1[, décroissant sur ]-1;1[, croissant sur ]1;+∞[
3. Maximum local en x=-1 : f(-1) = -1+3+2 = 4 → M(-1; 4) ; Minimum local en x=1 : f(1) = 1-3+2 = 0 → m(1; 0)
4. ∫₀² (x³-3x+2)dx = [x⁴/4 - 3x²/2 + 2x]₀² = (4 - 6 + 4) - 0 = **2**

**PROBLÈME II (8 points) — Probabilités**

Une urne contient 5 boules blanches et 3 boules noires. On tire successivement 2 boules SANS remise.

1. Construire un arbre de probabilités.
2. Quelle est la probabilité d'obtenir 2 boules blanches ?
3. Quelle est la probabilité d'obtenir au moins une boule blanche ?
4. Sachant qu'on a obtenu au moins une blanche, quelle est la probabilité que les deux soient blanches ?

*Corrigé :*
2. P(BB) = (5/8) × (4/7) = 20/56 = **5/14**
3. P(au moins 1 blanche) = 1 - P(NN) = 1 - (3/8)(2/7) = 1 - 6/56 = 1 - 3/28 = **25/28**
4. P(BB | au moins 1 B) = P(BB)/P(au moins 1 B) = (5/14)/(25/28) = (5/14)×(28/25) = **2/5**

**THÈME : La Génétique Moléculaire**

**QUESTION I (6 points)**
Un segment d'ADN a la séquence : 5'-ATGCCTAAGTTC-3'
1. Donnez la séquence du brin complémentaire.
2. Transcrivez ce segment en ARNm.
3. Donnez la séquence d'acides aminés correspondante (utiliser le code génétique fourni).

*Corrigé :*
1. Brin complémentaire 3'→5' : TACGGATTICAAG (règles A-T, G-C)
2. ARNm 5'→3' : AUG-CCU-AAG-UUC
3. Met - Pro - Lys - Phe (4 acides aminés)

Expliquez les étapes de la réponse immunitaire adaptative lors d'une infection bactérienne.

### BAC — Physique-Chimie Série C — Sujet Type

**EXERCICE PHYSIQUE (8 points) — Mécanique**

Une voiture de masse m = 1200 kg roule à v₀ = 90 km/h. Le conducteur freine brusquement.
Le coefficient de frottement entre les pneus et la route est μ = 0,6 et g = 10 m/s².

1. Convertir v₀ en m/s.
2. Calculer la force de frottement f.
3. Calculer la décélération a.
4. Calculer la distance de freinage d.

*Corrigé :*
1. v₀ = 90/3,6 = **25 m/s**
2. f = μ × m × g = 0,6 × 1200 × 10 = **7200 N**
3. a = f/m = 7200/1200 = **6 m/s²** (décélération)
4. v² = v₀² - 2ad → 0 = 625 - 12d → d = 625/12 ≈ **52,1 m**
