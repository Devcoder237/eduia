# Programme de Mathématiques — MINESEC Cameroun

## Primaire (SIL → CM2)

### Numération et Calcul
- SIL/CP : nombres de 0 à 100, addition et soustraction simples
- CE1/CE2 : nombres jusqu'à 10 000, multiplication (tables jusqu'à 10), division euclidienne simple
- CM1/CM2 : fractions simples (1/2, 1/3, 1/4), nombres décimaux, pourcentages simples (50%, 25%, 10%)

### Géométrie Primaire
- Figures planes : carré, rectangle, triangle, cercle, losange
- Périmètre du carré (4×c) et du rectangle (2×(L+l))
- Aire du carré (c²) et du rectangle (L×l)
- Symétrie axiale simple

### Mesures
- Longueurs : mm, cm, dm, m, km — conversions
- Masses : g, kg, tonne
- Volumes liquides : ml, cl, dl, l
- Temps : secondes, minutes, heures, jours, mois, années

## Collège (6ème → 3ème)

### 6ème — 5ème
- Nombres entiers, décimaux, fractions (addition, soustraction, multiplication, division)
- Proportionnalité et tableaux de proportionnalité
- Pourcentages avancés
- Angles, triangles, constructions géométriques
- Droites parallèles et perpendiculaires
- Aires des figures usuelles

### 4ème
- Équations du premier degré à une inconnue : ax + b = c
- Inéquations du premier degré
- Théorème de Pythagore : c² = a² + b² (dans un triangle rectangle)
- Statistiques : moyenne, médiane, mode, tableau de fréquences
- Probabilités élémentaires

### 3ème — Programme BEPC
- Trigonométrie dans le triangle rectangle : sin(α) = opposé/hypoténuse, cos(α) = adjacent/hypoténuse, tan(α)
- Fonctions affines : f(x) = ax + b — représentation graphique
- Racines carrées : √a, simplification, √(a²) = |a|
- Développements et factorisations : (a+b)² = a²+2ab+b², (a-b)² = a²-2ab+b², (a+b)(a-b) = a²-b²
- Translation et homothétie
- **Révisions BEPC** : épreuves types des années précédentes

## Lycée (2nde → Terminale)

### Seconde
- Fonctions : fonctions affines, carré, valeur absolue, inverse
- Équations et inéquations du second degré
- Vecteurs dans le plan : coordonnées, opérations, norme
- Statistiques et probabilités : loi des grands nombres, fréquences cumulées
- Trigonométrie : cercle trigonométrique, sin/cos/tan des angles remarquables (0°, 30°, 45°, 60°, 90°)

### Première (Séries C, D)
- **Dérivées** : définition, règles (somme, produit, quotient, composée)
  - (xⁿ)' = nxⁿ⁻¹ | (sin x)' = cos x | (cos x)' = -sin x | (eˣ)' = eˣ | (ln x)' = 1/x
- **Fonctions exponentielle et logarithme** : propriétés, équations, graphes
- **Suites numériques** : arithmétiques (u_n = u_0 + nr), géométriques (u_n = u_0 × qⁿ)
- Probabilités conditionnelles : P(A|B) = P(A∩B)/P(B), indépendance
- Équations de droites dans l'espace

### Terminale (Série C)
- **Intégrales** : définition, calcul ∫f(x)dx, interprétation comme aire
- **Limites et continuité** : définition, règles de calcul, théorème des valeurs intermédiaires
- **Nombres complexes** : forme algébrique a+bi, module, argument, forme exponentielle
- Loi normale : N(μ,σ²), standardisation, tables
- **Révisions BAC** : épreuves types BAC Cameroun séries C, D

## Examens Officiels Camerounais

### BEPC Mathématiques — Exemples de sujets types

**Exercice type BEPC (Algèbre)** :
Résoudre dans ℝ l'équation : 2x² - 7x + 3 = 0
Solution : Δ = 49 - 24 = 25 ; x₁ = (7+5)/4 = 3 ; x₂ = (7-5)/4 = 1/2

**Exercice type BEPC (Géométrie)** :
Dans un triangle ABC rectangle en A, AB = 6 cm et BC = 10 cm.
Calculer AC, puis sin(B) et cos(B).
Solution : AC = √(BC²-AB²) = √(100-36) = √64 = 8 cm ; sin(B) = AC/BC = 8/10 = 0,8 ; cos(B) = AB/BC = 6/10 = 0,6

### BAC Mathématiques Série C — Exemples de sujets types

**Problème type BAC (Analyse)** :
Soit f(x) = x³ - 3x² + 4. Étudier les variations de f, trouver les extrema, tracer la courbe.
Solution : f'(x) = 3x² - 6x = 3x(x-2) ; f'(x) = 0 ⟺ x=0 ou x=2 ; maximum local en x=0 : f(0)=4 ; minimum local en x=2 : f(2)=0

**Problème type BAC (Probabilités)** :
Une urne contient 4 boules rouges et 6 boules bleues. On tire 2 boules sans remise. Quelle est la probabilité d'obtenir 2 boules rouges ?
Solution : P = C(4,2)/C(10,2) = 6/45 = 2/15
